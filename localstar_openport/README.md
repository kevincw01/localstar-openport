# localstar-openport

Run the local Skyport weather and time server as a Home Assistant Supervisor
add-on/app. It serves multiple Venstar ColorTouch thermostats from one process,
independently of Home Assistant Core and the existing Venstar integration.

Supports 64-bit ARM (`aarch64`) and x86-64 (`amd64`). Installation builds the image
locally from this repository. See the Documentation tab for certificate setup,
configuration, network rules, and migration instructions.
